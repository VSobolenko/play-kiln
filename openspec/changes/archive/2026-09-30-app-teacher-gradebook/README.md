# app-teacher-gradebook

Private, offline classroom record book for teachers. The initial release has no account, no
server, no cloud sync, no ads and no analytics; it sells through a one-time Play Billing
unlock. It records classes, students, assignments, grades, attendance, participation, missing
work, parent contacts and seating, exports CSV and PDF through the system file picker, and
writes a backup file the teacher owns and can restore.
