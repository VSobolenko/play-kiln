# Coverkit — multi-platform social cover studio

**Date:** 2026-10-21  
**Slug:** `coverkit`  
**Plans:** `docs/ideation/plans/coverkit.{economics,differentiators,naming}.json`  
**Constraint:** **no AI provider keys** in v1 — local canvas, templates, brand kit, multi-export.  
**Owner approval:** 2026-10-21 — build Coverkit; OpenSpec `openspec/changes/app-coverkit/` (happy path first: arrive → tap → cover).

## The wedge (one sentence)

Design **once** with an offline **brand kit**, then export a **sharp native-resolution pack** for **YouTube + Instagram + TikTok + WhatsApp** in one action — without a subscription to save and without rebuilding the same cover in four apps.

## Product: a real studio, not a thin maker

### Who it is for
Creators and small brands who already post on **more than one** network and waste time resizing / redrawing the same idea.

### Core loop
1. **Brand kit** — logo, 2–4 colors, two fonts (saved on device).  
2. **Platform family** — pick destinations (YT 16:9, YT Shorts, IG post, IG story/reel, TikTok cover, WA status).  
3. **Edit** — layered canvas: photo (picker/camera), text+stroke, stickers/shapes, **safe-zone overlay** per platform.  
4. **Export pack** — one design → N PNGs at correct pixels + share sheet / SAF.  
5. **Projects** — reopen after kill; no “screenshot to save”.

### What we steal from competitors (their best)

| Source | Strength we absorb |
| --- | --- |
| YouTube Thumbnail Maker (10M+) | Bold creator stickers, arrows, channel-art mindset |
| StoryArt / StoryLab / Graphionica / Unfold (10M+) | Vertical story/reel canvases and template rows |
| InstaSize (50M+) | Correct sizes without stretching the subject |
| Canva (500M+) | Brand kit + multi-format thinking — **offline**, no account |
| Social Media Post Maker (1M+) | Network-first home, not a buried size list |

### What we fix (their shared failures)

| Failure (MEASURED complaints) | Our answer |
| --- | --- |
| Subscription / Pro to **save** | One-time unlock; free draft → pay at export/watermark |
| Blurry / distorted export | Native-resolution render per size; no downscale-then-upscale path |
| Projects vanish / force screenshot | Durable local project store + reopen tests |
| Pro locks old templates later | Bought unlock stays; no silent Pro strip |
| One app = one network | Multi-size pack is the product |

### Out of scope for v1 (honest)
- AI image generation / API keys  
- Video editing / Reels timelines (static covers only)  
- Canva-scale cloud template marketplace  
- Accounts / sync
