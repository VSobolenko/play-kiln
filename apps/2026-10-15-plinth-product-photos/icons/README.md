# Plinth icon set

Navigation - `arrow-left`, `x`, `chevron-right`: go back, dismiss, or move forward.
Actions - `plus`, `trash-2`, `share-2`, `download`, `refresh-cw`, `external-link`: create, delete, share, export, retry, or open a destination.
Discovery and status - `search`, `list-filter`, `check`, `triangle-alert`, `settings`, `info`: find, narrow, confirm, warn, configure, or explain.
Media - `camera`, `image`: capture or browse product imagery.

Lucide 0.468.0 upstream SVGs are preserved under `lucide-0.468.0/`; each VectorDrawable is an offline conversion using the same 24x24 path geometry, stroke width, round caps, and round joins. UI strokes resolve through the platform theme's `?android:attr/textColorPrimary`; the slot-owned Plinth mark is separate.
