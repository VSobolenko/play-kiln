# Lawn Round Log

**Slug:** `lawn-round-log`  
**applicationId:** `com.gexetr.lawnroundlog`  
**Idea:** An offline lawn round log a solo mower owns outright: ordered customers, one-tap visits, owed balances and CSV export, unlocked once.

PlayKiln slot — isolated Android attempt. Factory harness lives at the repo root.

## Build

```bash
# from this directory (JDK 17+ and Android SDK required)
./gradlew assembleDebug
./gradlew bundleRelease
```

Windows: `.\gradlew.bat assembleDebug`

If the Gradle wrapper JAR is missing, from a machine with Gradle installed:

```bash
gradle wrapper --gradle-version 8.11.1
```
