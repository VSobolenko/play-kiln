## en-US

### Title (25/30)

Laneset: Swim Set Builder

### Short description (76/80)

Build a paced swim set from your minutes, pool and gear. One unlock, no ads.

### Full description (2063/4000)

Laneset builds the swim session you actually have time for.

Tell it the minutes you have, the length of your pool, the day's focus, the strokes you want to avoid and the gear that is on the deck. Laneset computes a complete main set from those constraints against authored programming rules, so each session is a new arrangement of distances, strokes and send-offs rather than a slice of a fixed rotating library.

A TARGET TIME ON EVERY INTERVAL

Laneset walks you through a 400 and a 200 time trial, works out your threshold pace per 100 from those two swims, and prints that target on every interval it writes. No set is a bare distance with no time to swim it in, and the pace carries into the next session without asking again.

TAKE THE SET TO THE POOL

Share the whole set list as text, or print a workout card, so the session can be swum from paper or from a message. Already have a workout? Paste in the set your coach wrote and Laneset parses it into the same structured, paced session it generates itself.

BUILT FOR THE POOL DECK

• Works with no signal — the programming rules and the pace arithmetic live in the app, so a full session is generated with the phone in airplane mode.
• One purchase, everything included — no subscription, no renewal, no trial clock and no advertising.
• Comes back where you left it — a generated session survives a phone call, a rotation or a trip back to the locker with the same set, the same targets and the same place.

WHO IT IS FOR

Laneset is for the pool swimmer training three to six structured sessions a week in a masters or club lane, and for the triathlete doing their pool work — anyone who builds the session by hand today, or copies a coach's whiteboard, and does not want another monthly training subscription.

No account, no ads, no analytics. The app's own code opens no network connection and a full session is generated with no signal; the only network use is Google Play's own billing, which carries the one-time purchase. Google Play shows the exact price in your currency before you confirm.

## ru-RU

### Title (24/30)

Laneset: план тренировок

### Short description (70/80)

Тренировка по минутам, бассейну, инвентарю. Одна покупка, без рекламы.

### Full description (1935/4000)

Laneset собирает тренировку, на которую у вас действительно есть время.

Укажите минуты, длину бассейна, задачу дня, гребки, которые нужно исключить, и инвентарь на бортике. Laneset рассчитает основную часть по этим условиям и по заложенным правилам программирования, поэтому каждая тренировка — новая комбинация дистанций, гребков и интервалов, а не кусок фиксированной библиотеки.

ЦЕЛЕВОЕ ВРЕМЯ НА КАЖДОМ ИНТЕРВАЛЕ

Laneset проведёт вас через два заплыва на время — 400 и 200, — рассчитает по ним пороговый темп на 100 и подставит его в каждый интервал. Ни одна серия не останется просто дистанцией без времени, за которое её нужно проплыть, а темп сохранится для следующей тренировки.

ВОЗЬМИТЕ ТРЕНИРОВКУ НА БАССЕЙН

Отправьте весь список текстом или распечатайте карточку тренировки, чтобы плыть по бумаге или по сообщению. Есть готовая тренировка? Вставьте то, что написал тренер, и Laneset разберёт это в такую же структурированную сессию с темпом, какую строит сам.

ДЛЯ БОРТИКА БАССЕЙНА

• Работает без сети — правила и расчёт темпа находятся в приложении, поэтому тренировка строится полностью в режиме полёта.
• Одна покупка, всё включено — без подписки, без продления, без пробного срока и без рекламы.
• Возвращается туда, где вы остановились — тренировка переживёт звонок, поворот экрана или поход к шкафчику: тот же набор, те же целевые времена и то же место.

ДЛЯ КОГО

Laneset — для пловца, который тренируется три-шесть раз в неделю в дорожке мастерс или клуба, и для триатлета, делающего работу в бассейне: для тех, кто собирает тренировку вручную или переписывает её с доски тренера и не хочет ещё одну месячную подписку.

Без аккаунта, без рекламы, без аналитики. Собственный код приложения не открывает сеть, и тренировка полностью собирается без сигнала; сеть используется только для оплаты через Google Play, которая проводит разовую покупку. Google Play показывает точную цену в вашей валюте до подтверждения.
